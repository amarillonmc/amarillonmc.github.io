# 基本信息： #

**世界观：**（时空帧）『明日号』（＃０００００）

**名称：** 林苍月

**描述：**

时空特使最初的成员之一，同时也是时空特使中唯一一名没有正式编制、以"不记名者"身份活动的成员。极少有人能说清他的能力是什么——甚至连司令林仙凤也只是推测——但所有与他合作过的人都有一个共识：这个人永远醒着。

**设定：**

时空特使内编号：GA-00 / 编外

时空特使内Call Sign：PALE MOON

生日：不明

象征色：淡蓝与白

阵营属性：混沌·善

喜欢的图景：暗处行事，信息差，看别人自己想通问题。

讨厌的图景：必须亲自出面解决的麻烦，需要写报告的任务。

特殊能力："无能力者"

# 历史： #

说起林苍月，大多数时空特使成员的第一反应大概是"那个不睡觉的家伙"。确实，无论何时——凌晨三点、清晨六点、正午——只要你需要找他，他大概率醒着。没在硬撑，是真的不需要睡眠。有人怀疑这是他能力的一部分，有人觉得他就是体质特殊，而他本人对此只说"习惯了"。

实际上，林苍月的历史远比"不睡觉"厚重得多。

他是最早在明日号上醒来的三个人之一。与GA-01林仙凤、GA-02林彩光一起，三人发现自己身处空无一人的巨型舰船中，连自己是谁都要靠舰载AI告知。当时AI提出的第一个方案是用三人的基因模板复制更多成员——被三人一致拒绝。这个决定的最初发起者，正是林苍月。他的理由是："圆、正方形和三角形，描再多次边还是同样的形状。"

于是三人前往了AI指引的第一个时空帧。在那个全球与外星人交战的末日世界里，他们从南海孤岛的实验室中救出了一个八九岁的少女——后来的GA-04亚玛丽欧·维拉蒂安。林苍月是救援行动的提议者，也是第一个踹开实验室门的人。

但就在GA-04的培养完成前，林苍月因一次任务中的重大分歧，宣布脱离时空特使。

没人能确切说出那是什么分歧——林仙凤被问及时只会沉默片刻然后转移话题，林彩光则只是摇头。林苍月自己的说法每次都不一样，从"理念不合"到"没什么大事"到"我就是出去遛了一圈"。唯一可以确认的是，他的出走并非决裂——他仍然会回到明日号，仍然会协助亚玛丽欧的任务，只是不再受任何人的指挥。

时空特使的资料库中，他的档案状态被标注为"无能力者"与"编外人员"。林仙凤对此嗤之以鼻——"如果他是无能力者，那我就是普通人了。"但更多的话她也不说。大概是因为她也说不清楚。

# 故事中经历： #

**《常磐大逃杀》/《Elite Force ～华与泪与雨与雪》时：**

在时空特使检测到#104B6号时空帧的严重扰动后，GA-04亚玛丽欧原计划亲自处理此事。但由于她当时正忙于多个时空帧的并行任务，林苍月率先行动——他是第一个闯入虚拟幻境会场的人，也是在那之后第一个与红杀组织建立直接接触的人。

在湾城街头的一家模型店门口，他偶遇了红杀菁英蓝凝——发现她手里拎的不是武器，而是成袋的游戏光盘、桌游扩展包和限定手办。他以两倍于林无月的出价，当场将这位佣兵招募到了己方阵营。

此后，他多次潜入林氏软件公司内部，确认了"林岁星"接管公司的事实，并追踪了代号为"西装少女私兵"的不明势力——后来被证实为时空护卫五柱——在#104B6的活动。他还参与了时空特使二部的组建，为GA-04提供了关键的情报支援。

在最近的一次潜入行动中，林苍月被五柱成员知能（I-I）的无限分身追猎，被迫从林氏软件大楼跳下。目前仍在湾城活动。

# 其他： #

> 没能力，编外人员，不睡觉，到处跑。就这些了，有什么好写的。
>
> *——来自一份关于GA-00的补充问询的回复。据推测为林苍月本人所写。*

- 身高166cm，白发，蓝色眼睛。穿着就像一个普通高中男生——浅蓝色连帽衫、黑色高领内搭、深蓝色长裤、浅蓝色高帮球鞋。左耳有一个红色的心形耳钉，右耳有两个黑色小环。放在街上完全不会有人多看他一眼。

- 目前使用的武器不固定。曾在虚拟幻境中使用长剑和双叉，在其他任务中使用过符纸（据称为GA-42赛凡提供）。他也曾被目击搬运过一柄重约四十五斤的巨剑——虽然搬运时的表情称不上愉快，但动作毫不费力。

- 似乎认识许多时空特使成员，但很少有人声称"了解他"。蓝凝称他为"时空特使先生"，亚玛丽欧会用全名或者00（Double-O）称呼他。林仙凤偶尔叫他"那个熊孩子"。他自己不在乎被叫什么。

- 不喜欢写报告。从来没有提交过一份完整的任务报告——汇报是有，但口头说完就走，绝不留下任何书面记录。据说他的理由是"反正我这个编外写了也没人看"。这个习惯被林仙凤默许了。

- 因为从不睡觉，他的"下班时间"是一个不存在的概念。有记录显示他曾在同一天内出现在湾城、岳城和明日号三地，虽然这可能只是传言。但考虑到他的行动效率，没有人敢断言这只是传言。

- 关于他能力的唯一官方记录是"无能力者"。林仙凤曾在内部会议中提出这可能是一种"纯度较低、烈度较高的具象化能力"，但随后表示这只是推测，无法验证。亚玛丽欧在报告中写道："林苍月似乎什么都会一点。他总是在需要的时候刚好有能力处理问题。但我无法解释为什么。"

- 他的左耳红心耳钉和右耳双黑环是他身上最难忽视的细节——显眼是一回事，但在这个随时可以改换装束的人身上，它们似乎从没变过。

- 有一个关于GA-00的传说是：如果某件事在暗处被不声不响地解决了，而没有人能说清是谁做的——那多半就是他。不过他会否认的。
