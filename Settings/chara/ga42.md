# 基本信息： #

**世界观：**（时空帧）『明日号』（＃０００００）→ 将常驻＃１０４Ｂ６

**名称：** 赛凡（Sypher）

**描述：**

时空特使GA-42号成员，代号「电子道士」。以将特殊符纸贴附于目标来改变属性或获取信息的能力者，也是时空特使二部的核心成员之一。其性别时有变化——与其能力直接相关，因此在文档中尽量避免以确定性别的语言指代。

# 历史： #

赛凡并非在明日号上出生的GA成员。其来自另一个时空帧，在一个与"能力竞技"相关的世界中被GA-04亚玛丽欧·维拉蒂安发现，按照后者一贯的"废物利用"原则带回时空特使。

在#00000的培养和评估中，赛凡的能力被确认极具实用价值——其符纸可以覆盖情报收集、潜入支援、属性调整等多种任务场景。由于是亚玛丽欧直接带回的成员，赛凡跳过了常规的EA→GA晋升路径，直接作为亚玛丽欧的助手行动。

时空特使内对此安排并无异议。赛凡的能力本身说服了大部分人，而其"在自爆与复归方面颇有心得"的经历，则赢得了另一些战术口味独特的特工的敬仰。

----------

# 故事中经历： #

**《常磐大逃杀》时：**

在GA-04亚玛丽欧遭到来自#00000内部渗透者的刺杀未遂后，GA-01林仙凤下令成立独立于总部、保有最大权限的时空特使二部。亚玛丽欧任军长，赛凡作为副手自然从旅长提升任师长。

在此之前，赛凡已潜入敌方控制室——凭借符纸伪装接近目标——对敌方指挥官发动了代号「数据溢出」的玉碎指令。以八八六十四张符纸同时激活，将整层空间吞没在各色辉光之中。虽然这一击未能彻底消灭目标，但成功为二部的成立争取了宝贵时间。

玉碎后，赛凡在古道的巴士站等候牵引，搭乘巴士司机（同为GA成员，逆模因精神影响系能力者）的车辆返回#00000。随后向苏醒的亚玛丽欧汇报了任务结果，并参与了二部的组建。

二部转移至#104B6湾城港区车间后，赛凡被林仙凤调回#00000执行内部清查任务。任务完成后将前往#104B6常驻。

### 战斗风格

赛凡不是正面战斗员。其战术核心是**符纸**——通过预先准备或现场打印的符纸，可以：

- 隐藏自身或他人的存在（将透明度归零）
- 伪装成他人外貌
- 临时强化或削弱目标属性
- 在极端情况下，以玉碎指令将自身体质转化为大规模破坏力

战斗方式更接近"情报战"与"环境改造"，而非直接对抗。对于无法避免的正面冲突，其选择往往是：预先布好符纸网络，或在必要时刻毫不犹豫地执行玉碎。

# 其他 #

- 是时空特使内多数不老老实实穿制服的人之一。似乎更喜欢自己的披风——披风下可见蓝色的能力识别发光线路。
- 性别对其而言是可以随时变更的属性。今天可能是男性，明天可能是女性——全看当天贴的什么符纸。与其打交道时，与其纠结称呼，不如直接问名字。
- 据说在二部成立时，亚玛丽欧试图为其介绍身份时连续说错了两次性别，最终以"这个……东西"收场。赛凡对此的评价是："军长你莫非是消遣我？"
- 能力虽然强大，但有诸多限制。其一据说是"符纸必须亲手书写"——不过赛凡早已备好便携打印设备和大量预写符纸，这个限制在实战中很少成为瓶颈。
- 随身携带的标签打印机是其最重要的装备之一——可以在数秒内生成带SQL代码的符纸。
- 与GA-00林苍月的关系不错。两者的能力似乎在本质上有相似之处，实战中也多次配合——林苍月曾在潜入任务中使用赛凡的隐身符纸，效果令人满意。
- 在时空特使基层中拥有不低的声望。倒不是因为战斗力——而是因为三番五次自爆后又若无其事坐巴士回来的事迹，让一些特工真心觉得这种硬核的工作态度值得学习——至于为啥要自爆，大家也不会问的。
